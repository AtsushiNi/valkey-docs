# 付録 C. チェックリスト

本文で勧めた対策を、確かめる時点ごとに並べたものです。各項目の理由は、「詳しく」の章を参照してください。
問題が起きたときの症状から探すときは、19 章を使います。クラスターに関わる項目は、13 章のチェックリストにもまとめています。
