# 付録 A. 扱わない機能の一覧

この資料では、想定する使い方（RDB から作り直せる、API 向けの読み取り用データストア）で使わない機能は扱っていません。
将来、要件が変わったときに「こういう機能もある」と気づけるよう、名前と用途だけを挙げておきます。

| 機能 | 用途 |
|---|---|
| Bitmap / Bitfield | 文字列をビットの並びとして扱う。ユーザーごとのフラグや、日ごとのアクティブなユーザーの集計など |
| HyperLogLog | 少ないメモリで、重複を除いた件数（ユニークな訪問者の数など）を近似的に数える |
| Geo | 緯度と経度を保存し、ある地点からの距離や範囲で検索する |
| Pub/Sub | メッセージを、購読しているクライアントに配信する（保存はしない） |
| キースペース通知 | キーの変更や期限切れを、Pub/Sub のメッセージとして受け取る。ElastiCache Serverless では使えない |
| valkey-bloom | Bloom フィルター。「確実に存在しない」ことを、少ないメモリで高速に判定する |
| ベクトル検索（valkey-search の VECTOR） | ベクトル（埋め込み）の類似度で検索する。生成 AI やレコメンドなど |

これらは、薄く書く方針（使う可能性がある機能）にも入らない、「絶対に使わない」と決めた機能です。使う必要が出てきたら、公式のドキュメントで確認してください。
