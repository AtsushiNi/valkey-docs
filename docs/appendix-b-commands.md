# 付録 B. コマンド早見表

本文で使い方を説明したコマンドの一覧です。計算量の N の意味は、各章を参照してください。

「注意」の列の記号: ⚠ = 全体を止めうる・データを消しうる / S = ElastiCache Serverless では使えない

## キー全般

| コマンド | 用途 | 計算量 | 注意 | 詳しく |
|---|---|---|---|---|
| `DEL` | キーを削除する（その場で解放） | O(N)（大きなキーでは要素の数） | ⚠ 大きなキーは `UNLINK` を使う | 09 章 |
| `UNLINK` | キーを削除する（解放はバックグラウンド） | O(1)（キーごと） | | 09 章 |
| `TYPE` | キーの型を返す | O(1) | | 17 章 |
| `TTL` | 残りの有効期限（秒）を返す | O(1) | | 02 章 |
| `SCAN` | キーを少しずつたどる | 1回 O(1)、全体 O(N) | 同じキーが重複して返る。クラスターではノードごと | 02 章・09 章 |
| `KEYS` | パターンに一致するキーを一度に返す | O(N) | ⚠ S 本番では使わない | 02 章 |
| `RENAME` | キー名を変える（変更先があれば置き換える） | O(1)（置き換えられた値の解放を除く） | クラスターでは同じハッシュスロットのみ | 09 章 |
| `DBSIZE` | キーの数を返す | O(1) | クラスターではノードごとの値 | 17 章 |
| `SELECT` | DB 番号を切り替える | O(1) | 構成によって制約がある | 02 章 |
| `FLUSHDB` / `FLUSHALL` | すべてのキーを消す | O(N) | ⚠ `ASYNC` を付ける。権限で禁止する | 09 章・15 章 |

## String

| コマンド | 用途 | 計算量 | 注意 | 詳しく |
|---|---|---|---|---|
| `SET` | 値を書き込む | O(1) | オプション: `NX` / `XX` / `EX` / `PX` / `KEEPTTL` / `IFEQ` / `GET`。上書きで TTL が消える | 03 章 |
| `GET` | 値を読む | O(1) | | 03 章 |
| `MSET` / `MGET` | 複数のキーを書く・読む | O(N) | クラスターでは同じハッシュスロットのみ | 03 章・08 章 |
| `MSETEX` | 複数のキーに同じ TTL で書き込む（9.1） | O(N) | redis-py にメソッドがない | 08 章 |
| `INCR` / `DECR` / `INCRBY` | 整数として増減する | O(1) | | 02 章・03 章 |
| `INCRBYFLOAT` | 小数として増減する | O(1) | 誤差が出る | 03 章 |
| `DELIFEQ` | 値が一致するときだけ削除する（9.0） | O(1) | redis-py にメソッドがない | 06 章・09 章 |
| `STRLEN` | 値の長さを返す | O(1) | | 17 章 |

## Hash

| コマンド | 用途 | 計算量 | 注意 | 詳しく |
|---|---|---|---|---|
| `HSET` | フィールドを書き込む | O(N)（書き込むフィールドの数） | 指定しないフィールドは残る | 03 章 |
| `HGET` | 1つのフィールドを読む | O(1) | | 03 章 |
| `HMGET` | 指定したフィールドを読む | O(N)（指定したフィールドの数） | | 03 章 |
| `HGETALL` | すべてのフィールドを読む | O(N)（Hash のフィールドの数） | ⚠ ビッグキーでは使わない | 03 章 |
| `HDEL` | フィールドを削除する | O(N)（削除するフィールドの数） | | 03 章 |
| `HINCRBY` | フィールドを整数として増減する | O(1) | | 03 章 |
| `HLEN` | フィールドの数を返す | O(1) | | 03 章 |
| `HSCAN` | フィールドを少しずつ読む | 1回 O(1)、全体 O(N) | | 03 章 |
| `HGETDEL` | フィールドを読んで削除する（9.1） | O(N)（指定したフィールドの数） | | 03 章 |

## Set

| コマンド | 用途 | 計算量 | 注意 | 詳しく |
|---|---|---|---|---|
| `SADD` / `SREM` | 要素を追加・削除する | O(N)（追加・削除する要素の数） | | 04 章 |
| `SISMEMBER` | 要素が含まれるかを調べる | O(1) | | 04 章 |
| `SCARD` | 要素の数を返す | O(1) | | 04 章 |
| `SMEMBERS` | すべての要素を返す | O(N) | ⚠ 大きな Set では使わない | 04 章 |
| `SSCAN` | 要素を少しずつ返す | 1回 O(1)、全体 O(N) | | 04 章 |
| `SINTER` / `SUNION` / `SDIFF` | 積集合・和集合・差集合 | O(N×M) / O(N) / O(N) | ⚠ 大きな Set どうしは重い。クラスターでは同じハッシュスロットのみ | 04 章 |
| `SINTERCARD` | 積集合の件数だけを返す | `SINTER` と同じ | `LIMIT` で打ち切れる | 04 章 |
| `SINTERSTORE` | 積集合の結果を別のキーに保存する | `SINTER` と同じ | | 04 章 |

## Sorted Set

| コマンド | 用途 | 計算量 | 注意 | 詳しく |
|---|---|---|---|---|
| `ZADD` | 要素をスコア付きで追加する | O(log N)（1要素あたり） | | 04 章 |
| `ZREM` | 要素を削除する | O(log N)（1要素あたり） | | 04 章 |
| `ZSCORE` | 要素のスコアを返す | O(1) | | 04 章 |
| `ZCARD` | 要素の数を返す | O(1) | | 04 章 |
| `ZRANK` | 要素の順位を返す | O(log N) | | 04 章 |
| `ZRANGE` | 順位・スコアの範囲で取得する | O(log N + M)（M は返す件数） | `0 -1` で全件を取らない。`BYSCORE` の `LIMIT` の offset が大きいと遅い | 04 章 |
| `ZCOUNT` | スコアの範囲の件数を返す | O(log N) | | 04 章 |
| `ZINTER` | 積集合 | 要素の数に比例 | ⚠ クラスターでは同じハッシュスロットのみ | 05 章 |

| `XREAD` / `XREADGROUP` / `XACK` | Stream を読む・処理済みを記録する | — | | 04 章 |

## 複数のコマンド

| コマンド | 用途 | 注意 | 詳しく |
|---|---|---|---|
| `MULTI` / `EXEC` | トランザクション（まとめて不可分に実行） | ロールバックはない。クラスターでは同じハッシュスロットのみ | 06 章 |
| `WATCH` | 楽観的な排他制御 | | 06 章 |
| `EVAL` / `EVALSHA` | Lua スクリプトを実行する | ⚠ 長いスクリプトは全体を止める。キーは `KEYS` で渡す | 06 章 |
| `FUNCTION` / `FCALL` | 登録したスクリプトを実行する | S | 06 章 |

## 検索（valkey-search）

|---|---|---|---|

| `FT.INFO` | インデックスの状態を返す | redis-py では値を誤って解釈することがある | 07 章 |
